# Web research

1. Start with `web_search` for the query.
2. `web_fetch` 1–3 promising URLs.
3. Cite URLs in the final answer.
4. Separate facts from speculation.
5. If Instant Answer is empty, try alternate query phrasings or known authoritative URLs.
