# Knowledge search

1. `knowledge_list` to see available docs if unsure.
2. `knowledge_search` for keywords, then `knowledge_read` top hits.
3. Cite file paths in the answer.
4. If nothing local matches, say so — then optionally fall back to `web_search`.
